* Design notes :design:meta:

Org features map as follows:

| Org construct      | xanatoo node                          |
|--------------------+---------------------------------------|
| =* heading=        | Header (depth in =level=)             |
| =TODO= / =DONE=    | Header.=src=                          |
| =:tags:=           | Node.=tags= (=work:urgent=)           |
| =:CUSTOM_ID:=      | Node.=label= (stable =#anchor=)       |
| lists / checkboxes | List / ListItem (=task= / =task-done=)|
| =#+BEGIN_SRC=      | CodeBlock                             |
| =#+BEGIN_QUOTE=    | BlockQuote                            |
| pipe tables        | Table                                 |

:PROPERTIES:
:CUSTOM_ID: design-notes
:END:
